## Catatan Kerja Tim

1. Setiap anggota mengerjakan tugas sesuai pembagian peran.
2. Setiap anggota bertanggung jawab atas pekerjaan masing-masing.
3. Setiap perkembangan dan kendala pekerjaan dikomunikasikan kepada ketua tim.
4. Seluruh pekerjaan proyek dikoordinasikan melalui repository GitHub.
5. Setiap perubahan proyek harus dikelola dengan baik agar tidak mengganggu pekerjaan anggota lainnya.

## Penutup

Catatan pembagian peran ini dibuat sebagai pedoman kerja tim dalam melaksanakan pengembangan Layanan Antrean Kampus agar pekerjaan berjalan terarah dan terkoordinasi.

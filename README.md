Layanan Antrean Kampus

## Deskripsi Aplikasi

Layanan Antrean Kampus merupakan aplikasi yang dirancang untuk membantu pengelolaan antrean layanan di lingkungan kampus. Aplikasi ini bertujuan mempermudah mahasiswa dalam memperoleh layanan secara teratur serta membantu petugas dalam mengelola antrean.
